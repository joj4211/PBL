## Agent skills

### Issue tracker

Issue 放在 GitHub Issues（joj4211/PBL），透過 `gh` CLI 操作。See `docs/agents/issue-tracker.md`.

### Triage labels

使用預設的五個標籤：needs-triage、needs-info、ready-for-agent、ready-for-human、wontfix。See `docs/agents/triage-labels.md`.

### Domain docs

採 single-context 結構：根目錄放一份 `CONTEXT.md`，ADR 放在 `docs/adr/`。See `docs/agents/domain.md`.
